# Career Compass SG — Setup & Run

Module 1 Assignment · Group 7 · Singapore Jobs Analytics · **Topic: Career Recommendations**

A Streamlit dashboard that scores 215 Singapore career tracks on demand, pay, competition
and accessibility, built from 1,044,597 MyCareersFuture job postings.

---

## 1. Install

```bash
pip install -r requirements.txt
```

Requires Python 3.10+. The key packages are pandas, pyarrow, streamlit, plotly, matplotlib
and seaborn.

## 2. Build the data (first run only)

Place `SGJobData.csv` in the project root, then:

```bash
python src/etl_clean.py          # ~15 s — 1,048,585 rows in 6 chunks -> 3 Parquet files
python src/build_aggregates.py   # ~2 s  — 8 aggregate tables + Career Fit Score components
```

> **Why this step exists.** The raw CSV (273 MB) and the derived Parquet files (~145 MB)
> are **not in this repository** — the raw file is over GitHub's 100 MB hard limit, and the
> Parquet is fully reproducible from it in about 17 seconds. Ask the instructor for
> `SGJobData.csv`; everything else the dashboard needs is generated by the two commands
> above. The two small JSON outputs in `data/processed/` *are* committed, so you can read
> the cleaning audit trail without running anything.

To try the pipeline on a subset first, pass a row limit: `python src/etl_clean.py 50000`.

## 3. Run the dashboard

```bash
streamlit run app/Home.py
```

Opens at `http://localhost:8501`.

## 4. (Optional) Re-run the EDA notebook

```bash
jupyter lab notebooks/01_eda.ipynb
```

It reads from `data/processed/` and writes its figures to `reports/figures/`.

## Notes for markers

- **Every cleaning threshold lives in `src/config.py`** with a comment explaining why it is
  what it is, and the pipeline writes an audit trail to
  `data/processed/data_quality_report.json`.
- **The dashboard and the report share one implementation.** `app/utils.py` imports the
  scoring functions from `src/build_aggregates.py`, so the numbers on screen and the numbers
  in the report cannot drift apart.
- **Competition metrics are restricted to postings up to 2023-06-30.** The dataset is two
  stitched extracts and the view/application counters stop accumulating after that date. This
  is explained in the report (§2.6a), stated in the app, and is the single most important
  data-quality decision in the project.
- **Category shares overlap** and do not sum to 100%, because a job posting can belong to up
  to three categories.
